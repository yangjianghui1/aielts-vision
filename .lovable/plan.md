# 订单页 / 个人中心 / 机构合作页统一 Header/Footer

## 目标
根据用户上传的三张参考图，新建「订单确认页」「个人中心页」，并重做「机构合作页」，使三个页面的顶部导航与底部 Footer 与首页保持一致，其它主体内容按截图还原。

## 任务拆分

1. **订单确认页** (`src/routes/order.tsx`)
   - 路径：`/order`
   - 内容：左侧商品信息（IELTS Mock Test 标签、标题、核心权益包列表），右侧订单确认面板（报名项目 / 有效期 / 测评时间 / 日常价 / 应付总额 ¥299 / 微信安全支付按钮 / 用户服务协议）
   - 顶部返回课程列表按钮
   - 使用首页 `Header` 与 `Footer`

2. **个人中心页** (`src/routes/profile.tsx`)
   - 路径：`/profile`
   - 内容：左侧教务档案卡片（头像、手机号、注册时间、当前权益、订单/团队/佣金统计）、菜单导航（我的订单、功能兑换、成绩报告、账号设置、推广赚钱、我的团队、资产提现）、推荐入口；右侧「我的订单」表格（订单号、产品名称、数量、实付金额、购买时间、订单状态）
   - 使用首页 `Header` 与 `Footer`

3. **机构合作页** (`src/routes/partners.tsx`)
   - 路径：`/partners`
   - 按参考图重做：Hero「语焉雅思机构合作计划」+ 两个 CTA 按钮、4 项合作权益卡片、平台核心能力（含截图占位区 + 3 项能力卡片）、底部 CTA 横幅
   - 使用首页 `Header` 与 `Footer`

4. **统一 Header/Footer**
   - 三个页面均导入 `@/components/site/Header`
   - 三个页面均从 `@/components/site/StartCta` 导入 `Footer`
   - 确保导航锚点与首页一致

5. **验证**
   - 运行 `bun run build` 检查类型与路由生成
   - 检查三个页面渲染无报错
