# 官网静态预览页

这是语焉雅思官网首页的静态快照，可完全离线打开查看（双击 `index.html` 即可），方便研发在没有 Node 环境时也能看到页面真实视觉。

## 内容

```
preview/
├── index.html      首页完整静态 HTML
├── favicon.png     网站图标
└── assets/
    ├── site.css    全站样式（Tailwind 编译产物 + 品牌字体定义）
    └── files/      品牌字体（Akrobat / HarmonyOS Sans SC）、Logo、二维码、配图
```

## 说明

- 字体、图片、样式均为本地相对路径，不依赖外网。
- 这是「视觉快照」：滚动动画、交互（Tab 切换、手风琴展开等）已被静态化处理，全部内容默认展开可见。
- 锚点导航（产品能力 / 全真模考 / 会员方案 / 备考动态）在静态页内仍可点击跳转。
- 注册、预约等按钮指向线上站点，离线打开时点击会跳转线上地址。

## 研发参考

真正的前端源码在仓库 `src/` 下（React 19 + Tailwind CSS v4），结构说明见根目录 `FRONTEND_ONLY_GUIDE.md`。本目录仅用于快速预览与视觉对照。
